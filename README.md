- 보기: https://victorymankang-dot.github.io/scene_11.13/
- 파일 확인: https://victorymankang-dot.github.io/scene_11.13/scene.sog
- 주소 매개변수: 기본 시점은 촬영 첫 프레임 위치이고, `?view=auto`는 알갱이 분포로 자동 배치, `?pos=x,y,z&target=x,y,z`는 직접 지정입니다. `?file=scene.spz`처럼 다른 형식을 열거나 파일을 화면에 끌어다 놓아도 됩니다.

## 1. 고른 공간과 공개 판단

- 공간: 공원 야외에 놓인 자전거 선수 동상(받침대, 명패, 청동상, 자전거), 둘레는 포장 바닥과 나무.
- 공개 판단(한 줄): 야외에 상시 설치된 공공 조형물이고, 프레임 긴 변이 518픽셀이라 멀리 있는 사람은 몇 픽셀짜리 점으로만 남아 얼굴·차량 번호판을 알아볼 수 없다.
- 확인한 것: 추출한 24장을 모두 눈으로 봤을 때 멀리 작은 사람 몇 명(프레임 05~06, 09~10 부근, 0부터 센 번호), 먼 차량, 하늘의 드론이 있고 얼굴·번호판은 식별되지 않았다.

## 3. 복원 수치

| 항목 | 값 |
|---|---|
| 복원 시간 | 12.2초 (T4) |
| 최대 GPU 메모리 | 8.85 GiB |
| 점 개수 | 2,256,879개 → 각 축 위아래 0.5% 밖 제외 후 **2,203,476개** |
| 카메라 상자 크기 | 21.04 × 1.29 × 21.99 |
| 장면 상자 크기 | 79.96 × 13.59 × 69.43 |
| **카메라 퍼짐 비** | **0.2853** (카메라 상자 대각선 ÷ 장면 상자 대각선) |

**실제 촬영 경로와 비교.** 프레임을 순서대로 보면 처음에는 동상 정면 쪽에서 시작해 한 방향으로 돌아 뒷면 쪽에서 끝납니다. 복원된 카메라는 동상 쪽을 향한 시선이 모이는 점을 중심으로 반지름 9.0~11.3(평균 10.4)의 원을 따라 호 324.5°를 지납니다. 경로 길이 59.5는 반지름 10.4인 원둘레 65.4의 91%라서 "한 바퀴에서 약 35° 모자란 호"라는 눈대중과 맞습니다. 프레임 간 시선 회전은 평균 14.1°, 최대 20.8°입니다. 길이는 모델이 정한 척도라 미터로 환산하지 않았고, 실제 거리는 재지 않았습니다.

## 6. 잘 보이는 방향과 안 나온 자리

기본 시점은 촬영 첫 프레임 위치(원점)에서 동상을 보는 방향입니다.

**잘 보이는 곳.** 카메라가 지나간 원 위에서 동상을 바라볼 때입니다. 받침대 윤곽, 명패(갈색 사각형), 받침대 아래 계단형 단, 포장 바닥 위 희끄무레한 단이 알아볼 수 있습니다.

**검은 빈 곳과 번짐, 그리고 이유**

1. **하늘이 전부 검다.** 하늘은 무한히 멀어서 프레임마다 시차가 없고, 깊이 값을 정할 수 없습니다. 복원 때 깊이가 급히 바뀌는 가장자리를 지우는 옵션(`mask_edges`)을 켰고, 하늘은 깊이를 정할 근거가 없어 점으로 남지 않은 것으로 보입니다(원인은 복원 로그로 따로 확인하지 않았습니다).
2. **자전거와 청동상이 흐릿하고 하늘색이 묻는다.** 바퀴살처럼 가는 물체는 하늘과의 경계에서 깊이가 뒤섞이고, 위 가장자리 처리로 일부가 빠졌을 가능성이 큽니다. 화면에서 청동상 위쪽이 하늘색을 띠는 것도 같은 경계에서 하늘 색이 섞인 결과로 추정합니다. 프레임 간 시선이 평균 14°, 최대 20.8° 돌아서 가는 물체는 이웃 프레임에서 같은 모양으로 겹치기 어렵다는 점도 한몫합니다.
3. **받침대 앞면에 초록 얼룩이 박힌다.** 촬영 중 앞쪽을 지나는 사이프러스 덤불이 일부 프레임에서 가까이 있었고, 그 점들이 프레임 사이 정렬·깊이 오차로 받침대 앞에 겹쳐 남은 것으로 보입니다.
4. **바닥이 길게 늘어난 원판 줄로 보인다.** 카메라 위치가 거의 같은 높이에 있어서(카메라 상자 높이 1.29, 수평 21~22) 세로 방향 시차가 없습니다. 비스듬히 본 바닥은 한 프레임에서 얻은 점이 길게 늘어나고, 알갱이 반지름이 장면에서 가장 긴 변(80, 대부분 먼 배경이 만든 값)에 맞춰져 0.0754로 일정해 가까운 바닥에는 너무 큽니다. 먼 곳은 반대로 점이 드문드문 떠 있습니다.
5. **밖에서 보면 거대한 줄무늬 덩어리가 시야를 덮는다.** 원 바깥이나 아주 가까운 곳으로 시점을 옮기면 카메라 근처 나무 알갱이가 크게 그려져 화면을 채웁니다(`?view=auto`로 확인 가능). 이 방향은 촬영 카메라가 한 번도 서 본 적이 없는 자리라 점의 위치와 크기를 믿을 근거가 약합니다.
6. 방위각별 점 개수는 12.7만~28.6만으로 2.2배 차이가 났고 카메라는 30°당 1~3대였습니다. 호가 324.5°라 한쪽 약 35°는 직접 본 카메라가 없습니다.

## 7. 다시 만들려면

1. Colab T4에서 `map-anything` 설치 후 영상에서 24장을 뽑아 `model.infer(..., use_amp=True, amp_dtype="fp16")` 실행.
2. 각 축 0.5%/99.5% 밖 점 제외, y·z 부호 반전, 반지름 = 1.4 × 장면의 가장 긴 변 ÷ √N(0.075409), 불투명도 0.9, 구면 조화 계수 0차만으로 INRIA 형식 PLY 저장.
3. `npx -y @playcanvas/splat-transform@3.10.3 -w scene.ply scene.sog`
